# WP-03 · The How-to button and the tour, in plain language

## What was built

1. **A "How to" button** in the header, right next to "Load character". It has a little open-book picture.
2. **A popup called "Find your Valheim character".** It tells you where Valheim keeps your character file on Windows, macOS and Linux. Each folder path sits in a box with a **Copy** button. When you press Copy, the path goes onto your clipboard (the computer's copy-and-paste memory), and a note says "Path copied.". The popup guesses which computer you have and opens that tab first.
3. **A three-step tour.** Press **Show me around** in the popup and the page goes dark, except for a soft bright "hole" around one part of the page. A small paper note beside it explains that part. Click anywhere, or press the right arrow, to go on. The left arrow goes back, and Escape leaves the tour. The tour has no "Done" or "Skip" button on purpose: clicking anywhere is enough.

## Which files

| File | What it does |
| --- | --- |
| `src/tutorial/howto.js` | Makes the How-to button and the popup, and handles the tabs and the Copy buttons. |
| `src/tutorial/tour.js` | Runs the tour: finds each target, dims the page, places the note, and listens to the keys. |
| `src/tutorial/place.js` | Pure maths that decides where the note goes: right of the target, else left, else above (then below, then inside the window as a last resort). |
| `src/tutorial/platform.js` | Works out from the browser whether you are on Windows, macOS or Linux. |
| `src/tutorial/modal.js` | Makes the popup "modal": while it is open, the rest of the page can't be clicked or tabbed to. |
| `src/tutorial/toast.js` | Shows the "Path copied." note in the app's normal notification box. |
| `src/tutorial/tutorial.css` | How it all looks: paper notes, the dark cover and the bright hole. |
| `src/strings.js` | Every new sentence, and the table of save folders. |
| `src/config/render.js` | The `tour` numbers: how dark (35% brightness left), how soft the hole's edge is, gaps and widths. |
| `unit/tutorial.test.mjs`, `tools/wp03-check.cjs` | Automatic checks (see below). |

## How it works

- **Modal without the browser's own dialog.** Browsers have a built-in `<dialog>` popup, but it draws itself above everything, even the "Path copied." note. So instead the code sets `inert` on the rest of the page (an HTML switch meaning "you can't click, focus or read this right now") and keeps the Tab key looping inside the popup. When the popup closes, `inert` is removed and focus goes back to the How-to button.
- **Finding tour targets.** Each part of the page that the tour points at has a label attribute, `data-tour="load"`, `"board"` or `"stamps"`. The tour looks for whatever carries that label. Later, the 3D desk only has to put the same labels on its coins and bars, and the tour works there too.
- **The dark cover with a hole.** A transparent box sits exactly over the target. It casts an enormous shadow (`box-shadow` with a huge spread) that covers the rest of the screen in 65% black, and a blur softens the hole's edge.
- **Swallowing clicks.** While the tour runs, an invisible layer covers the whole window. Every click lands on that layer, not on the buttons underneath, so nothing on the page can be triggered by accident.
- **Screen readers.** Each note has `role="dialog"`, and focus moves into a fresh note at every step, so a screen reader reads the new step aloud.

## One thing to try

Open `src/config/render.js`, find `tour`, and change `dimTo: 0.35` to `dimTo: 0.1`. Run `npm run build:single`, open `dist/valheim-checkup.html`, press How to → Show me around. The page around the bright hole is now much darker. Change it back afterwards.
