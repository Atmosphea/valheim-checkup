# WP-07 in plain words: the paper layer

- Every word and control of the original app now sits printed on the paper: the big "Valheim Checkup" title, your name and records under it, the collection heading, the four stamps, the filters, the table, the help note and the footer. Same words, word for word.
- Behind the scenes these are still the original web page elements (same ids, same buttons), just moved onto the two sheets and drawn in 3D, so everything the old app did still works.
- Look: dark brown ink on parchment, old-style fonts (Grenze Gotisch for headings, IM Fell for the rest), stamps in green, red, blue and grey ink.
- Controls are printed too: menus are inked boxes, "Starred" is an inked square with a quill tick, search is an underlined line, Details and Export are boxed labels. Hover darkens the ink a little; pressing pushes it into the paper and it springs back.
- The help note is a sealed letter in the bottom-left corner; open it and it unfolds over the board.
- With no save loaded, the "Bring your Viking's progress with you" box prints where the stamps go.
- Light: the same light layer that shades the paper also shades the printed words, so a shadow over the paper darkens the text under it too. A warm candle-like glow (for the spark in a later step) can brighten the paper and the text.
- The paper slowly "breathes" (a tiny ripple), and breathes twice as much while you drag a file over the window.
- On a slow software renderer (no graphics card, like the test browser) the desk does its heavy start-up in one go while the page loads, so it doesn't freeze again later while you're using it.
- Files: `src/paper/` (index.js, layout.js, bristle.js, glow.js) and `src/styles/desk.css`.
- Try it: open the desk, press Tab a few times and watch the focus move coin → board → heading → stamps → filters → table → help → footer.
